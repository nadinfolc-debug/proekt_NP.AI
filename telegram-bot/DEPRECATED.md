# Устарело для персональных данных

Папка `telegram-bot/` **отключена** как обработчик ПДн (152‑ФЗ).

Ранее здесь были Cloudflare Worker + Turnstile + полная заявка в Telegram.  
Сейчас `worker.js` и `local-server.mjs` отвечают только `410` и **не** принимают заявки.

## Актуальная схема

- Backend: каталог `server/` на российском хостинге
- Сайт: `VITE_API_URL` → только этот backend
- Кабинет: `/admin`
- В VK — служебное уведомление без ПДн (номер + дата/время), если настроено в `server/`

## Не делать

- Не деплоить этот Worker для форм сайта
- Не задавать `VITE_NOTIFY_URL` / `VITE_TURNSTILE_SITE_KEY` в сборке сайта
- Не слать ПДн напрямую в Telegram / Cloudflare
