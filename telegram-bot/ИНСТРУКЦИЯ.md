# Инструкция: заявки с сайта в Telegram

Цель: когда кто-то заполняет форму **«Обсудить проект»**, вам в Telegram приходит сообщение с именем, контактом и задачей.

Ниже два варианта:
- **А** — быстрый тест на компьютере (5–10 минут)
- **Б** — чтобы работало на живом сайте GitHub Pages

Сначала всегда сделайте шаги 1–2.

---

## Шаг 1. Создать бота

1. Откройте Telegram и найдите **@BotFather** (официальный бот Telegram).
2. Нажмите **Start** / Отправить.
3. Напишите команду: `/newbot`
4. Придумайте **имя** бота (как будет отображаться), например: `NP.AI Заявки`
5. Придумайте **username** (должен заканчиваться на `bot`), например: `npai_prikolota_bot`  
   Если занят — попробуйте другой.
6. BotFather пришлёт **токен** — длинную строку вида:
   `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
7. **Скопируйте и сохраните токен** (в блокнот). Никому его не отправляйте.

---

## Шаг 2. Узнать свой chat_id

1. Найдите в Telegram **своего** нового бота (по username из шага 1).
2. Нажмите **Start** и напишите любое сообщение, например: `привет`
3. Откройте браузер и вставьте в адресную строку (замените `<ТОКЕН>` на свой токен):

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Пример:
```
https://api.telegram.org/bot7123456789:AAHxxx/getUpdates
```

4. На странице будет текст. Найдите фрагмент вроде:

```
"chat":{"id":123456789
```

Число `123456789` — это ваш **CHAT_ID**. Сохраните его.

Если страница почти пустая (`"result":[]`) — ещё раз напишите боту «привет» и обновите вкладку.

## Вариант А. Проверить у себя на компьютере

### А1. Файл настроек бота

В папке проекта откройте `telegram-bot` и создайте файл `.env` со таким содержимым (подставьте свои значения):

```
BOT_TOKEN=сюда_токен_от_BotFather
CHAT_ID=сюда_ваш_chat_id
SECRET=npai-secret-2026
PORT=8787
```

### А2. Запустить сервер уведомлений

В терминале Cursor / PowerShell:

```bash
cd "d:\Вейб - кодинг\Моштабный сайт\telegram-bot"
node local-server.mjs
```

Должно появиться: `NP.AI notify listening on http://localhost:8787`  
**Это окно не закрывайте**, пока тестируете.

### А3. Подключить сайт

В **корне** проекта (рядом с `package.json`, не внутри `telegram-bot`) создайте файл `.env`:

```
VITE_NOTIFY_URL=http://localhost:8787
VITE_NOTIFY_SECRET=npai-secret-2026
```

`SECRET` и `VITE_NOTIFY_SECRET` должны быть **одинаковыми**.

### А4. Перезапустить сайт

```bash
cd "d:\Вейб - кодинг\Моштабный сайт"
npm run dev
```

Откройте сайт → блок **«Обсудить проект»** → отправьте тестовую заявку.  
В Telegram должно прийти сообщение от бота.

Заявка также сохраняется в админке: `/admin`  
(логин: `nadin@admin.com`, пароль: `npai2026`).

## Вариант Б. Чтобы работало на GitHub Pages (интернет)

Локальный сервер из варианта А виден только у вас на ПК. Для публичного сайта нужен бесплатный Cloudflare Worker.

### Б1. Аккаунт Cloudflare

1. Зарегистрируйтесь на https://dash.cloudflare.com/ (если ещё нет).
2. Убедитесь, что установлен Node.js.

### Б2. Деплой

В терминале:

```bash
cd "d:\Вейб - кодинг\Моштабный сайт\telegram-bot"
npm install
npx wrangler login
```

Войдите в Cloudflare в браузере, затем:

```bash
npm run deploy
```

В ответе будет URL, например:

```
https://npai-telegram-notify.ВАШ_АККАУНТ.workers.dev
```

Скопируйте его.

### Б3. Секреты (токен не попадёт на сайт)

По очереди выполните и вставьте значения, когда спросит:

```bash
npm run secret:bot
```
→ вставьте **токен** бота

```bash
npm run secret:chat
```
→ вставьте **CHAT_ID**

```bash
npm run secret:key
```
→ вставьте секрет, например: `npai-secret-2026`

### Б4. Подключить сайт к Worker

В **корне** проекта обновите `.env` (и для продакшен-сборки лучше ещё `.env.production` с теми же строками):

```
VITE_NOTIFY_URL=https://npai-telegram-notify.ВАШ_АККАУНТ.workers.dev
VITE_NOTIFY_SECRET=npai-secret-2026
```

### Б5. Пересобрать и выложить сайт

Переменные `VITE_*` попадают в сайт **только при сборке**. После смены `.env`:

```bash
cd "d:\Вейб - кодинг\Моштабный сайт"
npm run build:gh
```

Скопируйте содержимое `dist` в `docs` (если у вас так принято) и запушьте изменения в GitHub — как обычно обновляете сайт.

Проверьте на живом сайте форму «Обсудить проект» — сообщение должно прийти в Telegram.

## Частые проблемы

| Проблема | Что проверить |
|----------|----------------|
| Бот молчит | Вы написали боту «привет»? Верный `CHAT_ID`? |
| На сайте «отправлено», в TG пусто | Запущен ли `local-server` / Worker? Совпадает ли `SECRET`? Перезапускали ли `npm run dev` после правки `.env`? |
| На GitHub Pages не приходит | `VITE_NOTIFY_URL` указан **до** сборки? После правки `.env` нужна новая сборка и push |
| `Unauthorized` | `VITE_NOTIFY_SECRET` ≠ `SECRET` у сервера |
| `getUpdates` пустой | Снова напишите боту и обновите страницу |

---

## Важно

- Токен бота **нельзя** писать в код сайта и в GitHub — только в `.env` у Worker / `telegram-bot/.env`.
- Файлы `.env` в git не коммитятся (уже в `.gitignore`).
- Пока Worker не настроен, заявки всё равно видны в `/admin` на том устройстве, где их отправили (localStorage).
