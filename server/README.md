# Backend заявок (РФ / локально)

Принимает формы, хранит полные заявки на диске сервера, отдаёт их только в кабинет после входа.  
В VK уходит **только** номер заявки, дата и время — без имени, контакта и текста задачи.

## Требование 152‑ФЗ

Размещайте этот сервер на **российском хостинге** (VPS Timeweb, Beget, Selectel и т.п.).  
Локальный запуск — для разработки и проверки. GitHub Pages / Cloudflare Worker **не** используют как хранилище ПДн.

## Быстрый старт (локально)

```bash
cd server
cp .env.example .env
# задайте ADMIN_PASSWORD (и при необходимости VK_*)
npm start
```

API: `http://127.0.0.1:8788`

В корне сайта `.env.development`:

```
VITE_API_URL=http://127.0.0.1:8788
```

Затем `npm run dev` в корне и откройте форму / кабинет `/admin`.

## Эндпоинты

| Метод | Путь | Назначение |
|-------|------|------------|
| POST | `/api/applications` | Публичная заявка |
| POST | `/api/auth/login` | Вход в кабинет |
| POST | `/api/auth/logout` | Выход |
| GET | `/api/auth/me` | Проверка сессии |
| GET | `/api/applications` | Список (нужен Bearer) |
| PATCH | `/api/applications/:id` | Статус (Bearer) |
| DELETE | `/api/applications/:id` | Удаление (Bearer) |

## VK

1. Управление сообществом → Настройки → Работа с API → ключ доступа (права на сообщения).
2. Узнайте `peer_id` админов (часто это числовой id пользователя).
3. В `.env`: `VK_ACCESS_TOKEN` и `VK_NOTIFY_PEER_IDS=123,456`.

Без токена заявки всё равно сохраняются; уведомление в VK пропускается.

## Когда ставить логин и пароль кабинета

**Момент:** сразу после заливки `server/` на VPS, **до** первого запуска и **до** открытия сайта людям.

1. Купили VPS, привязали домен, залили файлы.
2. Создали на сервере `server/.env`.
3. **Сейчас** прописали свой `ADMIN_LOGIN` и `ADMIN_PASSWORD`.
4. Только потом запустили backend (`npm start` / pm2) и проверили вход в `/admin`.
5. Уже после проверки — включаете сайт для посетителей.

Не откладывайте «на потом»: без пароля в `.env` кабинет не откроется, а тестовый пароль с ПК на прод тащить нельзя.

## Деплой на VPS в РФ

1. Скопируйте папку `server` на VPS.
2. Заполните `.env` (`HOST=0.0.0.0`, **свой** `ADMIN_LOGIN` / `ADMIN_PASSWORD`, `ALLOWED_ORIGINS` с доменом сайта).
3. `npm start` под systemd/pm2; лучше nginx + HTTPS.
4. В сборке сайта: `VITE_API_URL=https://ваш-домен.ru` (если API на том же домене через nginx).
5. Войдите в `/admin` своим логином/паролем и проверьте.

Данные: `server/data/applications.json` (не коммитьте).
